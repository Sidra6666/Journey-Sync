# 🚌 Journey Sync – Online Bus Reservation System

**Journey Sync** is a web-based bus reservation system designed to make bus travel easier and more convenient. It aims to improve the traditional ticket-booking experience with multi-destination booking, passenger reviews, ticket modifications, and email notifications.

## ✨ Features

- 🔐 **User Authentication** – Login and account management.
- 🚌 **Bus Search** – Select source, destination, travel date, and timing.
- 🎫 **Multi-Destination Booking** – Book journeys involving multiple destinations.
- ⭐ **Passenger Reviews** – Allow passengers to share feedback about their journeys.
- ✏️ **Ticket Modification** – Modify booking details, such as travel dates or passenger information.
- 📧 **Email Notifications** – Send booking-related notifications via email.
- 👨‍💼 **Admin Panel** – Manage bus details and schedules.
- 📱 **Responsive Interface** – Provide a user-friendly experience across different screen sizes.

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling and layout
- **JavaScript** – Client-side interactivity and responsive features
- **MySQL** – Database management

## ⚙️ How It Works

1. Users log in to the system.
2. They select their source, destination, travel date, and preferred timing.
3. They search for available buses and proceed with the booking process.
4. Users can manage eligible booking details and receive relevant notifications.
5. Administrators manage bus information and schedules.
